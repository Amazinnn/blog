这个博客是用一个 Python 脚本生成的。

没有用任何框架——没有 Astro、没有 Hexo、没有 Tailwind。一开始试过现成的模板，装着装着发现依赖占了 350MB，构建还超时了。后来想想，博客不就是几十个静态页面吗，自己搓一个也不难。

于是就写了 `build.py`。它做三件事：

- 读 `posts/` 目录下的 markdown
- 把每篇转成 HTML
- 加上一个首页列出所有文章

## 为什么这样就够

之前用模板的时候，花的时间大部分不是在写博客，是在跟配置和构建报错较劲。什么 `node_modules`、什么 lock 文件、什么版本不兼容。

**其实我需要的东西很简单：把文字变成网页。** 这个事情一个脚本就能干完，而且改一行 CSS 就能换风格，改一个函数就能加功能。
